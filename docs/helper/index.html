Как это работает

Маленький мост на вашем компьютере

Clod Helper ставит локальный мост. Выбранные программы отправляют трафик в него, а мост — на ваш прокси, с логином и паролем, без настройки в каждой программе.

Вы вставляете строку проксиЛюбой формат: программа сама разберёт адрес, порт, логин и пароль.
Мост запускается самВместе с Windows или macOS, следит за прокси и переключается на резерв.
Выбранное — через проксиClaude Desktop, браузер, терминал. Остальные программы — напрямую.
Установка

Две минуты — и готово

Windows

Windows 10 или 11 · файл Clod.Helper_…_x64-setup.exe

«Система защитила ваш компьютер»? Нажмите Подробнее → Выполнить в любом случае. Если файл не запускается — правой кнопкой по нему → Свойства → галочка Разблокировать → ОК.

macOS

macOS 11 и новее, Apple Silicon и Intel · файл Clod.Helper_…_universal.dmg

macOS не открывает программу? Правой кнопкой по Clod Helper в «Программах» → Открыть → Открыть. На macOS 15 и новее: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
