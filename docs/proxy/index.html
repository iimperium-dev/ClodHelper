Найдите IP сервера

Сервер создаётся несколько минут. Откройте «Мои серверы» в шапке сайта и нажмите «Подробнее…» у нового сервера. Подождите, пока вверху справа появится зелёная надпись «Включен».

  1. Подробнее… — откроется страница сервера.
  2. Основной адрес — это IP вашего сервера, четыре числа через точку, например 185.12.34.56. Ниже, в разделе «Сеть», рядом с ним есть кнопка «Копировать». Скопируйте IP и вставьте в шаге 5.
  3. Кнопка «Консоль» понадобится в шаге 6. Пароль от сервера (пользователь root) указан в «Учётных данных» — запоминать его не нужно, консоль вставит его сама.

Вставьте команду в консоль сервера

Консоль — это экран сервера прямо в браузере. Вверху у неё есть строка «Ввод текста»: туда вставляется текст, а кнопка «Отправить» печатает его на сервере.

Главное правило консоли: «Отправить» только печатает текст, но не нажимает Enter. После каждой отправки кликните мышкой по чёрному экрану и нажмите Enter на клавиатуре.

6.1Откройте консоль

На странице сервера нажмите «Консоль». Появится чёрный экран. Если он пустой — кликните по нему и нажмите Enter, появится строка login:.

6.2Войдите как root

В «Ввод текста» напишите root → «Отправить» → клик по экрану → Enter.
Появится Password: — нажмите «Вставить пароль» → клик по экрану → Enter. Пароль на экране не печатается — так и должно быть.

Консоль сервератак выглядит вход
Ubuntu 24.04 LTS svr tty1

svr login: root
Password:
Welcome to Ubuntu 24.04 LTS (GNU/Linux x86_64)

root@svr:~#

Видите root@…:~# — вы внутри сервера. Написало Login incorrect? Повторите 6.2 ещё раз, не спеша.

6.3Запустите установку

Скопируйте команду из шага 5 → вставьте в «Ввод текста» (Ctrl+V или кнопка «Из буфера») → «Отправить» → клик по экрану → Enter.

6.4Подождите 3–7 минут

Побегут строки [1/6] … [6/6]. Ничего не нажимайте, пока не появится рамка с надписью DONE! и двумя OK:

Если что-то пошло не так

      

        В конце написано FAILED
        
Чаще всего сервер просто ещё не до конца запустился. В панели 62yun нажмите «Перезагрузить», подождите 2 минуты, снова войдите в консоль (шаг 6.2) и выполните ту же команду ещё раз — повторный запуск безопасен.
Не помогло — сфотографируйте экран консоли и пришлите тому, кто дал вам эту инструкцию.

      

      

        Я потерял строку прокси
        
Откройте эту страницу в том же браузере — данные сохранены и строка уже готова в шаге 7.
Если браузер другой: войдите в консоль сервера и выполните короткую команду — скрипт покажет логин, пароль и порты заново, ничего не меняя:
curl -fsSL https://iimperium-dev.github.io/ClodHelper/proxy/install.sh | bash
Затем впишите IP, логин, пароль и порты в Clod Helper.

      

      

        Консоль не реагирует на текст
        
Кликните мышкой прямо по чёрному экрану — без этого клавиатура не попадает в консоль. Потом нажмите Enter. Если экран совсем завис, обновите страницу консоли (F5).

      

      

        Как сменить пароль прокси
        
В шаге 5 нажмите «Придумать другие», затем выполните новую команду в консоли (шаг 6). Старый пароль сразу перестанет работать — не забудьте заменить строку в Clod Helper.

      

      

        Хочу сервер в США, Германии или другой стране
        
Можно. В США и Канаде есть тариф promo-S за те же 269 ₽, в Германии самый дешёвый — promo-M за 399 ₽. Полная таблица по всем странам — в шаге 3. Остальные шаги не меняются.

      

      

        Сколько стоит и как продлевать
        
269 ₽ в месяц. На странице сервера включено «Продлевать сервер автоматически» — просто держите на балансе 62yun нужную сумму к дате продления. Если сервер не продлить, он выключится, и прокси перестанет работать.

      

      

        Это безопасно?
        
Логин и пароль создаются в вашем браузере и не уходят на наши серверы — у этой страницы их нет. Прокси закрыт паролем, на сервере открыты только порты прокси и вход для администрирования. Код скрипта открыт: install.sh.
Сервер и IP только ваши: никто, кроме вас, через этот прокси не ходит.

      

      

        Можно ли пользоваться прокси без Clod Helper
        
Да. Строки HTTP и SOCKS5 из шага 7 подходят для любых программ, браузерных расширений и телефонов, которые умеют работать с прокси. Clod Helper просто делает это удобно: прокси только для нужных программ и сайтов, остальное — напрямую.
