Подключите Claude Desktop

3 минуты

Claude Desktop умеет сам ходить через прокси — Clod Helper включает это одной кнопкой и заодно ставит защиту от утечек.

    {{#new}}
  1. Ещё нет Claude Desktop? Откройте в чистом браузере claude.ai/download, скачайте версию для своей системы и установите. Запускать пока не нужно.
    2. {{/new}}
  2. В Clod Helper откройте раздел Приложения. В строке Claude Desktop будет написано «Прокси Claude не настроен». Нажмите Подключить.
  3. Windows спросит разрешение на изменения — нажмите Да. Это один раз.
  4. Полностью закройте Claude Desktop, если он был открыт: правой кнопкой по значку Claude в трее (у часов) → Quit / Выход. Простого крестика окна мало — Claude останется работать в фоне.
  5. Откройте Claude кнопкой Открыть в строке Claude Desktop. Строка станет зелёной: «Через мост».

Удобнее с ярлыком. Правой кнопкой по строке Claude Desktop → Ярлык на рабочий стол. Появится ярлык «Claude Desktop (proxy)» — запускайте Claude им. Если Claude уже открыт, ярлык честно скажет закрыть его через трей и запустить снова.

В настройках Claude Desktop (значок ⚙ справа в строке) уже включены Не пускать мимо прокси и Не отправлять телеметрию. Оставьте их включёнными.

На Mac мастер уже подключил Claude Desktop сам — проверьте, что строка зелёная, и переходите дальше.
