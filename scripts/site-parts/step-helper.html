Установите Clod Helper

2 минуты
{{#upgrade}}

Clod Helper уже стоит? Обновите его до последней версии — программа сама предложит обновление, или скачайте установщик ниже и поставьте поверх. Затем замените прокси на свой: Прокси → Добавить → вставьте строку → Добавить в пул. Старый прокси уберите кнопкой с корзиной. Дальше переходите к следующему шагу.

{{/upgrade}}
  1. Скачайте установщик со страницы последней версии: для Windows — файл …x64-setup.exe, для Mac — …universal.dmg. Запустите его.
  2. Если Windows пишет «Система защитила ваш компьютер» — нажмите Подробнее → Выполнить в любом случае. Программа бесплатная и без платной подписи Microsoft, поэтому Windows осторожничает. Подробнее и для Mac →
  3. При первом запуске откроется мастер. Вставьте строку прокси из прошлого шага — формат любой, программа сама разберёт, где адрес, порт, логин и пароль. Нажмите Дальше.
  1. Дальше программа всё настроит сама — обычно меньше минуты. В конце появится Всё работает и адрес вашего сервера. Нажмите Открыть Clod Helper.

«Этот прокси в России»? Значит, сервер российский — Claude такой не примет. Нужен зарубежный: вернитесь к прошлому шагу.
